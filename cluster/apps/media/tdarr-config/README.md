# tdarr-config

Tdarr keeps its flows, libraries and worker limits in its own database, so this app makes them
declarative. A CronJob (`*/10`) runs [`app/config/sync.js`](app/config/sync.js) against the Tdarr API
and brings the live state in line with the files in [`app/config/`](app/config). It is idempotent: UI
edits to managed objects are reverted on the next run.

## What it manages

| File                            | Purpose                                                                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `flows/hc-tv.json`, `hc-movies` | HEVC (Intel QSV, 10-bit) flows, generated by [`scripts/tdarr-flow.py`](../../../../scripts/tdarr-flow.py). Do not hand-edit. |
| `libraries.json`                | The `TV` and `Movies` libraries (flow, folder, no folder watching).                                                          |
| `workers.json`                  | Per-node worker limits: GPU workers only, no CPU workers (CPU workers cannot use the GPU encoder and run ~40x slower).       |
| `lists.json`                    | Which arr quality profiles count as favourites (never transcoded).                                                           |
| `retire.json`                   | Pilot/legacy flows and libraries to delete.                                                                                  |
| `feed.json`                     | `enabled`: whether the job feeds the Tdarr queue. **Ships `false`.**                                                         |
| `priority-*.json`               | Queue order, generated by [`scripts/tdarr-priority.py`](../../../../scripts/tdarr-priority.py).                              |

Each run also refreshes two lists on the shared cache volume (`/temp/hc`, mounted by every node):
`skip-folders.txt` (favourites) and `foreign-originals.txt` (titles whose original language is not
English, so their audio is never stripped).

## Flow policy

Skip: HDR/Dolby Vision, above 1080p, remux, hardlinked files, favourites, anything already HEVC at
720p or below, and any file whose `.mkv` name would collide with an existing file. Otherwise encode to
HEVC 10-bit (global quality 21, preset slow), scale anything above 720p to 720p keeping the aspect
ratio, strip non-English audio and subtitles only when an English track exists, then verify duration
(within 1%) and size (10 to 100% of the original). Immediately before replacing the original it checks
the source is unchanged, so an arr upgrade mid-encode is never overwritten. Anything failing a check
goes to Tdarr's review queue with the original untouched. Radarr/Sonarr are told to rescan afterwards.

## Operating it

- **Start the backlog:** set `"enabled": true` in `feed.json` and merge. The job then feeds the queue in
  `priority-*.json` order (largest convertible titles first, titles watched in the last 90 days last),
  keeping about `QUEUE_BUDGET` files queued. Set it back to `false` to stop feeding; work already
  queued still runs.
- **Change policy:** edit `scripts/tdarr-flow.py`, run it, commit the regenerated flows.
- **Refresh priorities** (new downloads, watch history): run `scripts/tdarr-priority.py` (needs
  `kubectl` access; reads Sonarr/Radarr and the Tautulli history, which covers Plex plays only) and
  commit. Already-fed titles are tracked on the cache volume and are not re-fed.
- **One-time:** the job runs as UID 568 and writes `/temp/hc` on the shared cache volume; if that
  directory was created by root, `chown 568:568` it once.
- **Metrics:** `tdarr-exporter` serves Tdarr's statistics to VictoriaMetrics, with Grafana dashboard 20388.

The transcoder shares each node's iGPU with Plex and Jellyfin transcoding. If playback ever stutters
while Tdarr is busy, lower `transcodegpu` in `workers.json`.
